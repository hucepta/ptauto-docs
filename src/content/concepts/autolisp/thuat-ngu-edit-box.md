## Giải thích

Tile DCL cho phép người dùng nhập hoặc sửa một dòng văn bản; giữ nguyên dấu gạch dưới trong code.

**Cách hiểu trong khóa:** tile ô nhập liệu `edit_box`.

## Ví dụ liên quan

```text
: edit_box { key = "layer_chuan"; }
```
