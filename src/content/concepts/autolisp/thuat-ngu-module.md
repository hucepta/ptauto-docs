## Giải thích

Phần code có trách nhiệm và interface rõ, có thể được kiểm thử và quản lý độc lập hơn so với helper rời.

**Cách hiểu trong khóa:** mô-đun.

## Ví dụ liên quan

```text
Module validation dùng chung.
```
