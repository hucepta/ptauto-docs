## Giải thích

Ngôn ngữ mô tả hộp thoại, tile, thuộc tính và bố cục. DCL không thực thi logic AutoLISP; logic và vòng đời dialog do mã AutoLISP điều khiển.

**Cách hiểu trong khóa:** Ngôn ngữ điều khiển hộp thoại (Dialog Control Language).

## Ví dụ liên quan

```text
p6_ktlayerline : dialog { label = "Kiem tra layer"; ... }
```
