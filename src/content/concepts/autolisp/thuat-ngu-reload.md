## Giải thích

Nạp lại source đã Save để AutoCAD dùng phiên bản mới; trong phiên debug có thể cần Restart đúng ngữ cảnh.

**Cách hiểu trong khóa:** nạp lại.

## Ví dụ liên quan

```text
Ngoài debug: Save → load/reload → run. Trong debug: Save → Restart → run.
```
