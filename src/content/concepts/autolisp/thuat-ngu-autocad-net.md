## Giải thích

AutoCAD .NET là bộ API cho phép chương trình viết bằng ngôn ngữ .NET, thường là C#, tạo lệnh và đọc/ghi đối tượng trong bản vẽ AutoCAD. Mã được biên dịch thành plugin rồi nạp vào AutoCAD có phiên bản API tương ứng. Đây là một trong sáu lộ trình học trên trang này; người mới học AutoLISP không cần cài .NET để chạy file `.lsp`.

**Cách hiểu trong khóa:** nền phát triển .NET cho AutoCAD.

## Ví dụ liên quan

```text
AutoCAD .NET plugin
```
