## Giải thích

Định dạng tệp bảng đơn giản được nêu cho project luyện vòng đời file ngoài; khóa chưa dạy triển khai project này.

**Cách hiểu trong khóa:** định dạng dữ liệu phân tách bằng dấu phẩy.

## Ví dụ liên quan

```text
Tool xuất báo cáo CSV.
```
